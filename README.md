# DevSpace

**DevSpace** — это веб-платформа для Linux, превращающая ваше устройство (ПК, сервер или Raspberry Pi) в централизованный хаб для разработки и управления проектами.

Система предоставляет полноценное рабочее окружение, доступное через браузер, позволяя писать код и управлять файловой системой удаленно.

## 🚀 Основные возможности

*   **Управление проектами**: Создание проектов с привязкой к директориям, установкой иконок и описаний. Автоматическая генерация `README.md` при старте.
*   **Реестр проектов (SQLite)**: Надежное хранение метаданных. Если проект был удален с диска в обход интерфейса, система пометит его статус и предложит варианты действий (пересоздать или удалить запись).
*   **Веб-IDE**: Встроенный редактор для написания и правки кода прямо в браузере.
*   **Интеграция с Git**: Возможность инициализации репозиториев при создании проекта.
*   **Файловый менеджер**: Полный набор операций с файлами и папками внутри проектов.
*   **Внешний доступ**: Поддержка FTP/SFTP для подключения внешних клиентов.

## 🛠️ Технический стек

*   **Язык**: C++
*   **Сборка**: CMake
*   **База данных**: SQLite

## 🏗️ Сборка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/your-username/DevSpace.git
cd DevSpace

# Подготовка к сборке
mkdir build
cd build

# Конфигурация и сборка
cmake ..
make

# Запуск (примерный путь к бинарнику)
./DevSpace
